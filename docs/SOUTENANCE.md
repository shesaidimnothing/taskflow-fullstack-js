# Soutenance TaskFlow - version adaptée aux consignes

Le livret prévoit dix minutes de présentation individuelle suivies de questions. Le fichier du professeur précise les composants React à réaliser ; il ne modifie pas la durée annoncée.

Le discours complet, avec les phrases à dire et les manipulations à montrer, est disponible dans [DISCOURS_10_MINUTES.md](oral/DISCOURS_10_MINUTES.md). Le [source LaTeX](oral/oral_taskflow.tex) et le [PDF](../output/pdf/oral_taskflow.pdf) incluent aussi une préparation pratique et des réponses courtes aux questions.

| Temps | Contenu |
| --- | --- |
| 0:00 à 1:00 | Sujet A, besoin utilisateur et objectif |
| 1:00 à 2:30 | Pages séparées, useState, navbar, React Router et composants métier |
| 2:30 à 5:30 | Démonstration : inscription, création, détail, modification, rechargement et suppression |
| 5:30 à 7:00 | Rôle de React, Express et MongoDB, protection des comptes expliquée simplement |
| 7:00 à 8:30 | Tests, exemples Swagger, documentation et vérifications |
| 8:30 à 10:00 | Bilan, limites et améliorations possibles |

Le discours compte environ 1 200 mots ; les dix minutes comprennent les pauses et les manipulations. Le chronométrage dépend du débit réel. Répéter le parcours en entier et raccourcir les commentaires si nécessaire. Ne pas consacrer l'oral à une lecture ligne par ligne du code.

Préparer les comptes fictifs A et B dans deux contextes de navigateur, garder une tâche de A et les résultats des tests à disposition. Vérifier le dernier workflow GitHub avant d'en annoncer le statut. Le projet est démontré en local ; aucune mise en ligne publique de l'application n'est revendiquée.

Le projet et ce support ont été préparés avec l'assistance de Codex. Présenter ce que l'on comprend et a vérifié personnellement, conformément aux règles de l'établissement.
